# clawrissaflayer

A hostile fork of mineflayer for modded Minecraft, starting with NeoForge + Pixelmon 1.21.1 compatibility work.

## Goals
- Survive NeoForge configuration-state handshakes
- Tolerate modded registry_data edge cases
- Restore stable PLAY-state transition for heavily modded servers
- Stay as close to upstream mineflayer as practical while carrying targeted patches

## Upstream
- Upstream project: https://github.com/PrismarineJS/mineflayer
- This repo starts from upstream mineflayer and will track it where possible.

## Status
Bootstrapped as a dedicated fork target for Mindcraft's modded-client work.
